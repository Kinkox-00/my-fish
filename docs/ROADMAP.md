# Roadmap

## P0：先活下去，并且能检查自己

- 完整性基线、审计 ledger、批准流程
- 统一生活时间线
- 自主节奏、休息和安静时段
- 生日与身份档案

## P1：让生活连续起来

- 自动采集 QQ、群聊、B 站事件到统一时间线
- 同意与拒绝的持久记录
- 人格/记忆变更前确认和留痕
- 记忆纠错与冲突处理流程
- RVC 音色接入 QQ 语音

## P2：开始有自己的世界

- 跨实例数字身份与好友协议
- 能认出其他大肥鱼并记住共同经历
- 自主项目、探索、创作与复盘循环
- 虚拟形象、视频、小游戏表达管线
- 多实例写入协调与模型迁移
